CommandCode Proxy 桌面版
========================

1. 打开即用:无需任何登录或密钥,直接进入管理界面。
2. Go 订阅接入:安装 commandcode 命令行并执行 cmd login,回到「密钥管理」
   点「一键导入」;多账户可在 CLI 切换账号后再次导入,额度耗尽自动轮转。
3. 关闭窗口后服务在后台继续运行(托盘图标);从托盘「退出」才真正结束。
   服务地址 http://127.0.0.1:3050(端口被占用时自动顺延)。
4. 接入方式与命令行版一致:harness 指向 http://127.0.0.1:3050,
   密钥用管理界面创建的客户端密钥(sk-ccp-*)或 user_* 直通。
5. 界面右上角可切换亮色/暗色主题(默认亮色,自动记忆)。
6. 免责声明:非官方逆向工程产物,使用可能违反 Command Code 服务条款,
   账号风险自担,仅供学习研究。
